# Supply Chain Inventory Analytics

## Overview

An end-to-end supply chain analytics project focused on inventory monitoring, supplier quality, and operational KPI analysis.

The dataset was cleaned and prepared using Microsoft Excel and analyzed through an interactive Power BI dashboard.

## Tools Used

- Microsoft Excel
- Power BI
- DAX

## Project Workflow

1. Cleaned and validated the raw dataset using Microsoft Excel.
2. Prepared data fields for analysis and reporting.
3. Imported the cleaned dataset into Power BI.
4. Created DAX measures for operational KPIs.
5. Developed an interactive dashboard to monitor inventory and supplier performance.
6. Used slicers and drill-down analysis to investigate patterns across product categories and suppliers.

## Key Analysis

The dashboard focuses on:

- Opening Inventory
- Closing Inventory
- Reorder Levels
- Stock Status
- Supplier Performance
- Defect Rate
- Product Categories
- Inventory Risk
- Operational KPIs

## Dashboard

The Power BI dashboard provides an interactive view of inventory levels, stock exceptions, supplier quality, and operational performance.

## Key Features

- KPI cards for operational monitoring
- Stock status analysis
- Supplier defect-rate analysis
- Inventory vs. reorder-level monitoring
- Product-category analysis
- Interactive slicers
- Drill-down analysis

## Outcome

The project demonstrates an end-to-end analytics workflow from **Excel-based data cleaning and validation to Power BI dashboard development**, with a focus on identifying inventory and supplier-related exceptions.
